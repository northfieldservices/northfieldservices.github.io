Privacy Policy

Last updated: November 9, 2026

This policy covers the Northfield website and the Northfield Uploader, a small internal tool that Northfield uses to upload and schedule videos on its own YouTube channels.

Northfield Uploader and YouTube

The Northfield Uploader uses the YouTube API Services. It is used only by Northfield, for Northfield's own channels. It is not offered to the public.

  • What it accesses: with permission given through Google sign-in, it uploads videos, sets their titles, descriptions, thumbnails and schedules, and reads view counts for our own videos.
  • Where data is kept: the sign-in token and video statistics are stored only on Northfield's own computer. Nothing is stored on any server we run.
  • Sharing: we do not sell, share or transfer this data to anyone.
  • Removing access: access can be removed at any time on the Google security settings page. Stored data is deleted when access is removed or on request.

By using the YouTube API Services, this tool follows the YouTube Terms of Service and the Google Privacy Policy.

This website

This website does not use cookies, ads or tracking scripts, and it has no sign-up forms. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) under the GitHub Privacy Statement.

Emails

If you email us, we use your message only to reply. Every email we send includes a way to opt out, and we honour every opt-out.
